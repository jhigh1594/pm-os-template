# /strategic-build — Build or Not

**Canonical skill:** `.claude/skills/strategic-build/SKILL.md`

Applies the LNO (Leverage / Neutral / Overhead) framework to evaluate whether a specific work item, feature, or initiative is worth building. Answers the question: "Given everything competing for our attention, should we do this?"

## Usage

`/strategic-build [specific work item, feature, or initiative]`

## Best Uses

- "Should we build the Salesforce integration this quarter?"
- "Is the custom dashboard configurability worth the engineering cost?"
- "Evaluate whether the [product] API redesign is leverage or overhead right now"
- "We have 3 competing requests — help me assess which are leverage vs neutral"

## Notes

- Distinct from `/think` (big strategic direction) — this is item-level work evaluation
- Distinct from `/prioritize` (ranking a list) — this is whether to do something at all
- Distinct from `/reframe` (changing how you think) — this is a concrete build/no-build decision
