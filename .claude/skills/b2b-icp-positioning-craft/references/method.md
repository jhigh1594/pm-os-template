# Method

Use this method to move from broad market thinking to a narrow ICP and clear positioning.

## Core Principle

Treat ICP as a focus decision, not a description exercise.

Treat positioning as the external expression of that focus.

Aim for the smallest repeatable segment where:
- the pain is real
- the champion cares now
- the current product wins for a differentiated reason
- the buying signal comes from behavior, not polite interest

## Sequence

### 1. Clarify the decision

Identify what decision the work is meant to support.

Common decision types:
- choose the first wedge
- refine an existing ICP
- explain weak conversion in a segment
- connect discovery to positioning
- produce qualification or messaging assets

Do not start with templates before the decision is clear.

### 2. Form a provisional ICP hypothesis

Define 3-5 attributes only.

Prefer attributes like:
- company size or stage
- role or champion
- painful workflow
- tech environment
- trigger event
- buying context

Avoid broad definitions like:
- "enterprise companies"
- "mid-market SaaS"
- "heads of product"

### 3. Identify the champion

Determine:
- who feels the pain first
- who makes the shortlist
- who can carry the deal internally

Separate the champion from:
- economic buyer
- stakeholders
- influencers
- blockers

Anchor the ICP on the champion first.

### 4. Map alternatives from the buyer's point of view

Ask:
- if this product did not exist, what would the buyer do?

Always include:
- status quo
- internal workaround
- direct competitor
- adjacent tool or substitute

Do not use internal company framing unless it matches the buyer's real decision set.

### 5. Assess signal quality

Use evidence in this order:
- observed behavior
- clean-market response
- repeated conversion pattern
- repeated urgency language
- stated preference
- hypothetical interest

Prefer:
- outbound response
- conversion rate differences
- faster time to close
- stronger urgency
- repeated implementation pull

Discount:
- investor intros
- friendly conversations
- praise without action
- one unusual customer
- internal excitement without external proof

### 6. Run the "so what?" ladder

Start from the capability.

Ask "so what?" until the value lands in buyer-language terms.

Example:
- feature: query runs 1000x faster
- so what: support team gets answers faster
- so what: customer issues get resolved sooner
- buyer-valued outcome: improve response speed for customers

Stop before the value becomes generic, such as:
- "improve efficiency"
- "save time"
- "reduce cost"

### 7. Separate value from objections

Keep distinct:
- value = reason to buy
- objection = reason the buyer may hesitate

Typical value themes:
- faster revenue motion
- better decision quality
- reduced operational drag
- improved customer outcomes

Typical objections:
- deployment effort
- change management
- switching cost
- integration complexity
- total cost of ownership

Do not force objections into core positioning unless the champion truly buys for that reason.

### 8. Produce the smallest useful artifact

Choose the smallest output that supports the decision:
- ICP brief
- champion profile
- alternative map
- positioning canvas
- qualification questions
- proof and objection table

Use `references/templates.md`.

## Expansion Rule

Expand the segment only after repeatable wins appear.

Use these signals to justify expansion:
- repeated wins in a narrow wedge
- clear understanding of why those wins happen
- proof that the same value logic transfers to an adjacent segment

Do not expand because the broader market feels more exciting.

## Default Response Shape

When enough context exists, produce:
- ICP hypothesis
- not-for segment
- champion definition
- alternative map
- signal assessment
- differentiated value
- positioning draft
- next validation steps

When context is weak, still produce:
- a provisional call
- the main uncertainty
- the next questions or data to collect
