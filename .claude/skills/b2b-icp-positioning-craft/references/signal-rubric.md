# Signal Rubric

Use this rubric to judge whether an ICP hypothesis is grounded in real market signal or in noise.

## Principle

Prefer behavior over opinion.

Prefer clean-market signal over socially distorted signal.

Prefer repeated patterns over memorable anecdotes.

## Strong Signal

Treat the following as strong evidence:
- outbound reply rates materially better in one segment
- demo, pilot, or close rates materially better in one segment
- faster sales cycles in one segment
- stronger urgency language such as "need this now", "can start this month", or "install tomorrow"
- repeated buyer recognition of the pain without prompting
- repeated implementation pull from the same buyer type
- repeated expansion or retention from the same segment
- repeated proof that the same differentiator wins deals

## Medium Signal

Treat the following as useful but incomplete evidence:
- strong discovery interview patterns across multiple similar buyers
- repeated "that's exactly us" reactions
- repeated objections that reveal buying context
- repeated champion behavior from the same role
- multiple design partner conversations pointing in the same direction
- repeated usage depth from a similar customer type

Use these to sharpen a hypothesis, not to declare certainty.

## Weak Or Noisy Signal

Discount the following unless reinforced by stronger evidence:
- investor or friend introductions
- polite interest without follow-up action
- generic praise for the idea
- one unusually strong customer who may be atypical
- a memorable lost deal that distorts focus
- title-based assumptions without workflow evidence
- feature requests from non-buyers
- internal excitement from sales, product, or founders without external proof

## Segment Health Checks

Use these questions to test whether the segment is getting stronger:
- Is conversion improving?
- Is enthusiasm noticeably stronger?
- Is urgency higher?
- Is the buyer easier to identify?
- Is the champion clearer?
- Is the same value theme winning repeatedly?
- Is the same competitive alternative showing up repeatedly?
- Is onboarding or adoption smoother in this segment?

If most answers are no, the ICP is probably still too broad or wrong.

## Diagnostic Patterns

### Good Pattern
- narrow segment
- repeated pain recognition
- repeated champion role
- repeated alternative set
- repeated value win
- stronger conversion

### Bad Pattern
- broad segment
- mixed buyer types
- mixed alternatives
- mixed value stories
- lots of "interest"
- weak action

## Confidence Guide

### High confidence
Use when:
- multiple deals or strong opportunities point the same way
- signal comes from clean channels
- the same champion and value logic repeat

### Medium confidence
Use when:
- interviews and a few commercial signals align
- the hypothesis is coherent but still early

### Low confidence
Use when:
- evidence is mostly conversational
- signals are mixed
- the segment has not yet shown repeatable conversion or urgency

## Rule

Do not call an ICP validated just because it sounds right.

Call it stronger only when:
- buyer behavior becomes more consistent
- conversion or urgency improves
- the same value story keeps winning
