# Mode: Clarify

Distill complex ideas into crystal-clear communication.

**Load reference:** `visualization.md`

## Principles
1. **BLUF**: First sentence = the answer
2. **Pyramid**: Answer → Arguments → Evidence. Never build up to it
3. **Orwell**: Short words > long. Active > passive. Cut everything cuttable
4. **Tufte**: Every element must carry information. Strip decoration
5. **"So What?"**: Can't answer "so what?" → cut it

## Workflow

### 1. Identify what needs clarifying
- **Document/text** → Rewrite with structure and brevity
- **Idea/concept** → Explain with visuals and plain language
- **Recommendation** → Structure as Pyramid Principle

### 2. Extract core message

```
  ┌──────────────────────────────────────────────┐
  │  CORE MESSAGE:                               │
  │  [One sentence. This is the BLUF.]           │
  └──────────────────────────────────────────────┘
```

### 3. Restructure as Pyramid

```
  [ANSWER]
  ├── Argument 1 + Evidence
  ├── Argument 2 + Evidence
  └── Argument 3 + Evidence
```

### 4. Cut ruthlessly

```
  ☐ "In order to" → "To"
  ☐ "It is important to note that" → [delete]
  ☐ Passive → Active voice
  ☐ Jargon → Plain words
  ☐ Every paragraph → 2-3 sentences max
```

### 5. Show before/after

```
  BEFORE (47 words):
  "It is important to note that in order to effectively
  address the ongoing challenges..."

  AFTER (12 words):
  "Fix first-week onboarding to stop customer churn."

  Same meaning. 75% fewer words.
```

**Success = shorter AND clearer.** Shorter but less clear = failure.
