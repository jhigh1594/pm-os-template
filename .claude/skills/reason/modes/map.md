# Mode: Map

Visualize any concept, system, or idea using ASCII art.

## Workflow

1. Determine what needs visualizing → pick format
2. Build the visual (SIMPLEST that captures the concept)
3. Add ONE sentence insight below

### Format guide

```
  WHAT TO SHOW             USE THIS FORMAT
  ──────────────────────────────────────────────
  Hierarchy / structure    →  Tree
  Decision flow            →  Flowchart
  Two dimensions           →  2x2 matrix
  Before/after             →  Side-by-side
  Process steps            →  Timeline / funnel
  System components        →  Stack / layer diagram
  Trade-offs               →  Triangle / comparison
  Status / progress        →  Progress bars
```

Depth levels: default (one diagram), brief, deep.

**One great diagram > three mediocre ones.**
