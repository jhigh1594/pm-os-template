# Mode: Invert

Think backwards using Munger's inversion.

## Workflow

1. State the goal
2. List 5-10 things that GUARANTEE failure
3. Map each to a prevention action
4. Rate severity (High/Med/Low)
5. Synthesize into non-negotiables

```
  GUARANTEED FAILURE           PREVENTION
  ─────────────────────────────────────────
  [Failure mode 1]          →  [Action]
  [Failure mode 2]          →  [Action]
  [Failure mode 3]          →  [Action]

  ┌──────────────────────────────────────┐
  │  NON-NEGOTIABLES:                    │
  │  1. [Must-do #1]                     │
  │  2. [Must-do #2]                     │
  │  3. [Must-do #3]                     │
  └──────────────────────────────────────┘
```

**Avoiding stupidity is more reliable than seeking brilliance.**
