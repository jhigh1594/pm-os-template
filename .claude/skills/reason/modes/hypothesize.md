# Mode: Hypothesize

Form and test hypotheses. Move from "we don't know" to "here's what we think and how to verify."

## Workflow

1. Frame the uncertainty (what, stakes, current beliefs)
2. Form 2-4 competing hypotheses (specific, falsifiable, actionable)
3. Design fastest test that eliminates the most uncertainty
4. Build decision tree for outcomes

```
  ┌─────────────┐
  │  Hypothesis │
  └──────┬──────┘
         │ Test
    ┌────┴────┐
    ▼         ▼
  CONFIRMED  REFUTED
    │         │
    ▼         ▼
  [Action A] [Action B]
```

**The goal is NOT to be right. The goal is to learn fast.**
