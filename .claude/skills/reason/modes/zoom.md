# Mode: Zoom

Switch altitude on any problem.

## Workflow

1. Identify current altitude (Strategic/Operational/Tactical)
2. Show all three levels for the SAME problem
3. Check alignment between levels
4. Recommend the right altitude to resolve the issue

```
  30,000 ft ═══ STRATEGIC ═══
  ┌─────────────────────────────────────────────┐
  │  [What does winning look like? Why?]       │
  └─────────────────────────────────────────────┘
                    │
  10,000 ft ═══ OPERATIONAL ══
  ┌─────────────────────────────────────────────┐
  │  [How do we organize to win? Quarterly?]   │
  └─────────────────────────────────────────────┘
                    │
   Ground    ═══ TACTICAL ═════
  ┌─────────────────────────────────────────────┐
  │  [What do we do this week/sprint?]         │
  └─────────────────────────────────────────────┘
```

Shortcuts: `out` = one level up, `in` = one level down, `all` = map all three.
