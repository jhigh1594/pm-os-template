# Mode: Frame

Reframe any problem. Identify the real problem vs symptoms, classify using Cynefin.

## Workflow

1. Understand context (ask MAX 3 sharp questions if needed)
2. Expose the real problem using 5 Whys
3. Classify using Cynefin (Complex/Complicated/Chaotic/Clear)
4. Decompose via MECE issue tree
5. Write a sharp problem statement with metric + constraint
6. Suggest next steps (/reason, /reason invert, /reason decompose)

**NEVER** restate the problem in different words. ADD INSIGHT.
